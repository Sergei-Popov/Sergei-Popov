- **Backend и данные:** REST API, графовые движки сценариев, состояние диалогов, фоновые задания, транзакции и конкурентный доступ.
- **Frontend:** визуальные редакторы на React Flow, операторские панели, управление состоянием, контроль конфликтов сохранения, WebSocket и SSE.
- **AI и интеграции:** RAG, поиск по корпоративным знаниям, LLM API, MCP и function calling, интеграции с мессенджерами, 1С и внешними сервисами.
- **Инженерные практики:** общие frontend/backend-контракты, разграничение доступа, тесты API и E2E, контейнеризация, автоматические проверки и мониторинг.
